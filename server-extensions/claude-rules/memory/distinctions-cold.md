## Demoted 2026-08-08 (WP-484 Ф77, M2 budget — освобождено место под новую строку Pull-on-Touch)

- **settings.json ≠ settings.local.json** → проектный vs персональный. Редко триггерится; конфликт этих файлов — разовая, не повторяющаяся ситуация.
- **Доставляемый артефакт ≠ Сервис** → артефакт копируется к пользователю; сервис = один инстанс. Нишевое для платформенной архитектуры, не общедневная работа.
- **Pack ≠ Программа развития** → поле/домен (онтология) vs курс развития роли. Актуально только в момент создания Pack/курса (pack-creator scope).
- **Vault ≠ Pack ≠ Файловая система** → хранилище с интерфейсом vs онтологический тип. Командный Vault уже устарел (см. demoted 2026-07-12); личный Vault-кейс редок.
- **Нумерация шагов протокола** → буквенные суффиксы уникальны в файле; вставка → дробный формат. Актуально только при авторстве/правке protocol-*.md, не general work.
- **Профиль ошибок агента ≠ DayPlan** → для агента (инжекция) vs для пилота (артефакт). Узко к WP-316, не general distinction.
- **DRR-запись ≠ Pack-текст** → решение = owner (SoT); правку решения начинать с DR-записи. Узко к Pack-authoring workflow (pack-creator).
- **Состояние объекта ≠ Стадия процесса** → кто объект есть vs шаг воздействия на него. Абстрактное, не привязано к текущему активному РП.
