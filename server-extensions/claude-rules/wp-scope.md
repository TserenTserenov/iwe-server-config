# WP Scope Rules

Any wp-context: read only `pending`/`in_progress`/`blocked` phases; skip done/closed/defer unless the user asks or the task needs one (long done-tails waste tokens). Umbrella cards with `agent_scope: open-only` (WP-5, WP-7): mandatory, no implicit-need exception. Actualization, any card and its archive: `grep` closed items by subject name and read the hits — pilot decisions live there (WP-561 Ф60).
