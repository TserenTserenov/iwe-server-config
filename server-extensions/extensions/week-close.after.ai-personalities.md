# Week Close — команда ИИ-личностей (РП-510)

**Когда выполнять:** в Части Б, после статусов РП и до финального коммита Week Close. Это расширение существующего ритуала, а не отдельная встреча.

## Свод в WeekReport

Добавить ровно одну секцию `## Команда ИИ-личностей (РП-510)`. Для каждой именованной личности из `current/AI Personalities Registry.md` указать только проверяемые строки:

- новые уроки за неделю: источник, отношение `accepted_by` или `available_to`, и результат применения в новом контексте;
- повторные ошибки: число подтверждённых случаев, субъект и ссылка на профиль ошибок;
- достижения: наблюдаемый результат, проверивший и ссылка на свидетельство;
- дрейф характеристик: показатель, метод наблюдения, диапазон, свежесть и уровень доказательности;
- непринятые кандидаты опыта и просроченные гипотезы: владелец решения и следующий шаг.

Если для строки нет адресуемого источника, написать `нет данных`; не выводить из отсутствия записи ни рост, ни отсутствие ошибки. `available_to` не считать усвоением, а runtime-инференс Honcho не считать фактом или аттестацией.

## Минимальная проверка перед коммитом

```bash
REGISTRY="$HOME/IWE/DS-my-strategy/current/AI Personalities Registry.md"
REPORT_FILE="$HOME/IWE/DS-my-strategy/current/WeekReport W{N} YYYY-MM-DD.md"

grep -q '^## Команда ИИ-личностей (РП-510)$' "$REPORT_FILE" || {
  echo 'РП-510: секция команды ИИ-личностей отсутствует'; exit 1;
}
rg -n '^(\*\*)?(Элар Церенович|Кир|Корис|Гари)(\*\*)?' "$REGISTRY"
rg -n 'accepted_by|available_to|нет данных' "$REPORT_FILE"
```

**Критерий РП‑510:** три последовательных Week Close содержат эту секцию с адресуемыми источниками. До третьего прогона обещание О4 остаётся в проверке.
