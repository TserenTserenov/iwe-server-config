# Day Close — Before Extension

## Готовый дайджест дня (вместо ручного пересчёта)

Запустить один раз, до шага 1:

```bash
bash "{{HOME_DIR}}/IWE/DS-my-strategy/scripts/day-close-prepare.sh" --no-ledger
```

Вывод покрывает секции, которые протокол ниже иначе собирал бы заново по отдельности: коммиты за сегодня по репозиториям (шаг 1), open-sessions.log (шаг 2d), дрейф памяти (шаг 4б), здоровье индексов (шаг 4в), WakaTime (шаг 6.1), peer-сессии за сегодня из `sessions/00-index.md` (шаг 6.2, prerequisite мультипликатора), рефлексия за день. Использовать этот вывод на соответствующих шагах вместо повторного `git log`/grep — не пересчитывать то, что уже здесь. `--no-ledger`: только чтение, факт в ledger по-прежнему пишется один раз на шаге 5б протокола (повторный вызов с записью создал бы дубль события).

## Peer-session guard

Если пользователь сказал «в пир-сессии с Кими» / «peer-сессия» / «вместе с Кими» / «с участием Кими» — запустить Day Close через скилл `kimi-peer-writer`, а не напрямую.

Проверить контекст текущего сообщения пользователя:
- если содержит: «пир-сессии», «peer», «с Кими», «Kimi» — **СТОП**. Не запускать day-close solo.
- Сообщить: «Обнаружен модификатор пир-сессии. Запускаю через kimi-peer-writer.»
- Вызвать: `Skill(skill="kimi-peer-writer", args="Day Close <дата>")`
- После запуска kimi-peer-writer — не продолжать шаги day-close solo.
