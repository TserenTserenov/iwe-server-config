## Заявка на время пилота (РП-561 Ф55, контракт v3 DR-06)

Если сессия открыта по РП (`WP-N`, не `outside-wp`) и пилот в ней участвует,
подать одну заявку на его время сегодня с оценкой агента. Автономные прогоны
без пилота заявку не подают.

**Оценка в минутах.** Если Ритуал согласован, взять его «Оценку» и перевести в
минуты (~1.5h → 90). Если Ритуал не нужен (продолжение того же РП), назвать
пилоту свою оценку этой сессии одной фразой. Оценки нет — заявку не подавать:
без оценки запроса нет, ноль и значение «на всякий случай» не подставлять.

`<id сессии>` — номер сессии из `session-guard.sh open` (слаг пир-сессии или
выданный id): по нему заявка видна в дневной сводке. Повторно за ту же сессию
не подавать.

**На «Цехе»** (есть приёмник `/run/iwe-plan-bridge/receiver.sock`):

```bash
python3 "$HOME/IWE/DS-my-strategy/scripts/plan-session-reserve.py" \
  --wp WP-N --session "<id сессии>" --minutes <оценка>
```

**На Маке** (есть ключ `~/.ssh/iwe-plan-mac`): заявка уходит на «Цех» по
отдельному каналу Мака. Ключ умеет только это и ответ на сводку.

```bash
ssh -i "$HOME/.ssh/iwe-plan-mac" -o IdentitiesOnly=yes -o BatchMode=yes \
  -o ConnectTimeout=10 iwe-plan-mac@95.216.75.148 \
  reserve --wp WP-N --session "<id сессии>" --minutes <оценка>
```

Нет ни приёмника, ни ключа — заявку не подавать и пилоту не сообщать.

**Код выхода:**
- `0` — заявка и отметка о начале поданы. Сказать пилоту одной фразой: «Заявка
  на N мин на сегодня подана». Решение по бюджету дня принимает мост; заявка
  сверх бюджета будет отклонена.
- `3` — на этом хосте нет приёмника. Ничего не отправлено, пилоту не сообщать.
- `1` — приёмник отказал: показать пилоту код отказа, вручную не повторять.
- `2` — команда не дошла до приёмника или вход неверен: показать причину.
- `4` — заявка подана, а отметка о начале не дошла. Повторить ту же команду,
  добавив в конец `--resume-start <reservation_event_id из ответа>`: уйдёт
  только отметка, второй заявки не будет. Без отметки на эту заявку завтра
  нельзя будет ответить.
- `5` — очередь была занята на всех попытках, ничего не записано: повторить
  ту же команду через минуту.
- `255` (только Мак) — нет связи с «Цехом»: сказать пилоту «Заявка не подана:
  нет связи с „Цехом“». Одну попытку можно повторить позже в этой сессии.
