## Заявка на время пилота (РП-561 Ф55, контракт v3 DR-06)

Сессия открыта по РП (`WP-N`, не `outside-wp`), и пилот в ней участвует. Тогда
подать одну заявку на его время сегодня с оценкой агента. Автономные прогоны
без пилота заявку не подают.

**Оценка в минутах.** Если Ритуал согласован, это его «Оценка», переведённая в
минуты (~1.5h → 90). Если Ритуал не нужен (продолжение того же РП), назвать
пилоту свою оценку этой сессии одной фразой. Оценки нет — заявку не подавать:
без оценки запроса нет, ноль и значение «на всякий случай» не подставлять.

```bash
python3 "$HOME/IWE/DS-my-strategy/scripts/plan-session-reserve.py" \
  --wp WP-N --session "<id сессии>" --minutes <оценка>
```

`<id сессии>` — номер сессии из `session-guard.sh open` (слаг пир-сессии или
выданный id): по нему заявка видна в дневной сводке. Повторно за ту же сессию
не подавать.

**Код выхода:**
- `0` — заявка подана. Сказать пилоту одной фразой: «Заявка на N мин на сегодня
  подана». Решение по бюджету дня принимает мост; заявка сверх бюджета будет
  отклонена.
- `3` — на этом хосте нет приёмника (сейчас Мак). Ничего не отправлено, пилоту
  не сообщать.
- `1` — приёмник отказал: показать пилоту код отказа, вручную не повторять.
- `2` — команда не дошла до приёмника или вход неверен: показать причину.
