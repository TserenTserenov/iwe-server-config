# Month Close — срез здоровья (РП-470)

## Шаг A3. Срез «Здоровье (РП-470)»: локальный файл + указатель в MonthClose (БЛОКИРУЮЩЕЕ при наличии базы)

**Когда выполнять:** ПОСЛЕ шага 10 (Запись `archive/MonthClose YYYY-MM.md`), ДО шага 11 (Коммит) — рядом с шагом A1 (multiplier-trend).

**Резидентность (WP-469 retrofit-audit, фаза WP-7 DayPlan-Health-Residency, 2026-07-24):**
`archive/MonthClose YYYY-MM.md` коммитится и пушится на GitHub — health-ЗНАЧЕНИЯ в него
попадать не должны. Скрипт пишет полную секцию (недели + тренд + маркер покрытия) в
локальный файл `~/Library/IWE/health-data/month-summaries/YYYY-MM.md` (вне git), а в
stdout отдаёт только строку-указатель без значений — её и вставляем в MonthClose.

**Дизайн среза (решение пилота 2026-07-18, чат):** вид «недели + тренд», три метрики
(сон, пульс покоя, плавание), обязательный маркер покрытия («N из D дней»). Точка
потребления — локальный файл; стоп-листы стратсессии этот срез не читают.

**Что сделать:**

```bash
# MONTH — ЗАКРЫВАЕМЫЙ период (шаг 1a), НЕ текущий месяц: Month Close запускается
# в первый Пн следующего месяца и закрывает прошлый.
MONTH="YYYY-MM"  # из шага 1a
REPORT_FILE="$HOME/IWE/DS-my-strategy/archive/MonthClose $MONTH.md"

# Идемпотентность: указатель уже есть (повторный прогон) — не дублировать.
if grep -q "Здоровье (РП-470)" "$REPORT_FILE"; then
  echo "month-close.after.health: строка-указатель уже присутствует — пропуск (idempotent)"
else
  bash "$HOME/IWE/extensions/month-close.summary-extra.sh" "$MONTH" >> "$REPORT_FILE"
fi
```

**Инвариант:**
- В MonthClose — ТОЛЬКО строка-указатель без значений; сами цифры (сон/пульс/плавание) — только в локальном файле вне git. Значение в MonthClose = нарушение резидентности WP-469, блокер коммита.
- Данных нет → скрипт пишет честную заглушку без значений, строка всё равно присутствует — тихий пропуск запрещён (тот же принцип, что в Day Open).
- Вывод скрипта детерминированный (SQLite), LLM его не переписывает.
- Скрипт author-only (личные данные), в FMT-exocortex-template не поставляется — L1 вызывает его только через этот extension-файл.

**Проверка перед коммитом:** `grep -c "Здоровье (РП-470)" "$REPORT_FILE"` → ровно 1 (указатель есть, не продублирован), и в MonthClose нет строк вида `| W[0-9]* (...) | *ч |` из health-таблицы. Если 0 — шаг не выполнен, коммит отложить.
