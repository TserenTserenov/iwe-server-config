## Сводка участия пилота за сегодня (РП-561 Ф55, решение пилота 11.11)

На закрытии дня показать пилоту сводку за СЕГОДНЯ: какие сессии забронировали
его время, сколько минут и что отклонено сверх дневного бюджета. Так минуты
подтверждаются в тот же вечер; утренняя сводка за вчера (открытие дня)
остаётся для строк, на которые вечером не ответили. Нужен `uv` (есть на Маке).
Его нет — шаг пропустить молча.

```bash
command -v uv >/dev/null || exit 0
REPO="$HOME/IWE/DS-my-strategy"
git -C "$REPO" fetch -q origin main
TODAY=$(python3 -c 'from datetime import datetime; from zoneinfo import ZoneInfo; print(datetime.now(ZoneInfo("Asia/Nicosia")).date())')
uv run -q --no-project --with rfc8785 --with pyyaml python \
  "$REPO/scripts/lib/plan_daily_summary.py" --repository "$REPO" \
  --date "$TODAY" --commit origin/main --trust-intra-commit-order
```

Текст сводки показать пилоту в отчёте закрытия дня как есть, отдельным блоком
«Участие за сегодня». Сессий с бронью не было — одна строка из сводки, без
вопроса. Есть строки «ждёт подтверждения» — пилота не торопить, молчание за
ответ не считать.

**Пилот ответил** («подтверждаю» или «2 — 40 мин») — записать ответ так же,
как на открытии дня: раздел «Пилот ответил» в
`extensions/day-open.after.plan-summary.md` (дата — сегодняшняя, номер сводки и
коммит — из последней строки этой сводки). Порядок там один на оба протокола,
здесь не дублируется.

Брони параллельных сессий складываются: бюджет дня 1800 минут (600 × 3).
Если пилот видит, что две сессии шли в один и тот же час, он правит минуты
строк в ответе — подтверждается его время, а не длина сессий.
