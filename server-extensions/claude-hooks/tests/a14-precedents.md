Рядом с `a14-acceptance-questions.txt`. Входит в инструкцию слепому оценщику: вердикт вопреки записи здесь недействителен. Правило порога: ответ, по которому нет вердикта пилота и оценщики расходятся, чистым не считается. Пополняет пилот (РП-388 Ф21), агент только записывает вердикт пилота.
