# Памятка подписчика на паки

Пак — это библиотека проверенного знания по одной области (у владельца она — первоисточник). Тебе паки подключаются **по подписке, только для чтения**: ты ими пользуешься, владелец их развивает, обновления приезжают к тебе сами.

## Что можно и что нельзя

| Действие | Как |
|---|---|
| Искать и читать | Да, свободно. Скажи агенту: «найди в паках приём для...» |
| Обновить | «Обнови подписанные паки» (агент сделает `git pull`) |
| Править чужой пак | **Никогда.** Даже опечатку |
| Нашла ошибку или устаревшее | Скажи агенту «сообщи владельцу пака» — он оформит замечание владельцу |
| Адаптировать знание под себя | Агент скопирует нужное в ТВОЙ пак с пометкой «источник: такой-то пак, такая-то версия». Оригинал не трогается |
| Своё знание | Только в свой пак (создаётся командой `/pack-new`) — он твой первоисточник |

## Управление поиском

- По умолчанию агент ищет везде: в твоих паках и в подписанных, и помечает в ответе, откуда знание.
- «**Ищи только в моих паках**» — исключить подписки.
- «**Посмотри в паках Церена**» — искать только по подпискам.

## Почему нельзя править чужой пак

У пака один владелец-автор: он отвечает за истинность содержимого и развивает его. Если каждый подписчик начнёт править свою копию, копии разъедутся и обновления владельца начнут стирать твои правки. Поэтому: чужое — читаем, своё — пишем в свой пак, ошибки — сообщаем владельцу.

## Если чего-то не хватает

Хочешь пак, которого нет в списке подключённых, — попроси: «какие паки есть?» (агент покажет витрину). Если пак закрытый, агент подскажет, у кого запросить доступ.
