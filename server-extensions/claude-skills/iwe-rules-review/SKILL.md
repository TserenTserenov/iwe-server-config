# Ревью культуры работы IWE

> **Триггер:** Week Close (автоматически) или вручную.
> **Роль:** R1 Стратег.
> **Вход:** DP.M.008 (Pack) + данные за неделю (коммиты, DayPlans, Quick Close отчёты).
> **Выход:** Предложение изменений → одобрение → обновление DP.M.008 + реализаций.

## When to use

Еженедельное ревью культуры работы IWE (элемент 14 — Эволюция системы). Запускается при Week Close.

## Algorithm

### 1. Загрузить правила

Прочитать `PACK-digital-platform/pack/digital-platform/03-methods/DP.M.008-iwe-operating-rules.md` → §2 Реестр (14 элементов культуры работы).

### 2. Четыре вопроса (по каждому правилу)

| # | Вопрос | Источник данных | Действие |
|---|--------|----------------|----------|
| 1 | **Чему научился?** | Quick Close отчёты, captures за неделю | Зафиксировать новые знания |
| 2 | **Какое правило мешало?** | DayPlans, git diff | Правило нереалистично → упростить / убрать |
| 3 | **Какого правила не хватало?** | fleeting-notes, уроки memory/ | Повторяющийся паттерн без правила → кандидат на формализацию |
| 4 | **Какое правило обходил?** | Quick Close отчёты | Систематически обходится → кандидат на перенос (с указателем) или переработку; удалять правила нельзя (решение пилота 05.11.2026). Мёртвый вес = иллюзия контроля |

### 2а. Горячее ядро (WP-7 Ф299, блок 5)

Горячее ядро — то, что читается в каждой сессии (CLAUDE.md и `.claude/rules/**/*.md`). Три команды, только чтение:

```bash
python3 "$HOME/IWE/scripts/hook-delivery-audit.py" --hours 168 --json      # доставка хуков за неделю
python3 "$HOME/IWE/scripts/rule-usefulness.py"                             # кандидаты на перенос (отчёт)
python3 "$HOME/IWE/scripts/hot-budget-ratchet.py" waivers > "<папка отчёта недели>/hot-budget-waivers-$(date +%F).md"
```

- Снимок исключений из храповика сохраняется файлом в папку отчёта недели — это неизменяемый след для аудита; исключение с прошедшей датой пересмотра (пометка «ПРОСРОЧЕН») выносится пилоту отдельной строкой.
- Список кандидатов на перенос показывается пилоту, только если доля доставки хуков за неделю не ниже 95 % (в выводе аудита `persisted_ratio` ≤ 0,05) и с 05.11.2026 прошло не меньше 14 дней. Иначе в отчёт одна строка: «перенос не предлагается: доставка не подтверждена» с цифрой.
- До карты правил (блок 4 плана) это только отчёт: ничего не переносится, правила не удаляются никогда. Переносит пилот или агент по его решению, с указателем в старом месте и проверкой каждого переноса.
- В таблицу «Здоровье» добавить строки: «Горячее ядро, токенов» (из строки храповика), «Доставка хуков за неделю, %», «Кандидатов на перенос».

### 3. Сформировать отчёт

```markdown
## Ревью культуры работы IWE (W{N})

### Здоровье

| Метрика | Значение | Норма |
|---------|----------|-------|
| Нарушений за неделю | N | 0-2 |
| Не применялось >2 нед | N правил | 0-1 |
| Кандидатов на новое правило | N | 0-2 |

### Нарушения

| # | Правило | Сколько раз | Причина | Предложение |
|---|---------|-------------|---------|-------------|

### Мёртвый вес

| # | Правило | Последнее применение | Предложение |
|---|---------|---------------------|-------------|

### Кандидаты на формализацию

| Паттерн | Источник | Предлагаемое правило |
|---------|----------|---------------------|

### Итого

- Изменений в DP.M.008: N (перенести с указателем: ..., добавить: ..., изменить: ...)
- Изменений в реализации: N (CLAUDE.md, protocol-*.md, skills/)
```

Хотя бы одна строка данных в таблице «Нарушения» ИЛИ «Кандидаты на формализацию»
непустая (критерий детерминированный, не самооценка: строка данных есть и хотя бы
одна её ячейка ≠ `—`/пусто/только пробелы — не заголовок таблицы без строк) → факт
М17 (WP-522 §М, пир-сессия 2026-08-31-30): вызвать писателя, best-effort. Согласование
в §4 для факта НЕ требуется — применение правок в DP.M.008 отдельно от самого факта
«ответил содержательно»:
```bash
python3 "${IWE_WORKSPACE:-$HOME/IWE}/${IWE_GOVERNANCE_REPO:-DS-my-strategy}/scripts/post-culture-fact.py" \
  --element M17 --mode record --evidence "<N нарушений>/<M кандидатов> в ревью W<N>" \
  >/dev/null 2>>"${IWE_RUNTIME_DIR:-$HOME/IWE/.iwe-runtime}/culture-fact-errors.log" || true
```

### 4. Согласование

Показать отчёт → пользователь одобряет → применить изменения в DP.M.008 и реализациях.
