# /diagnose --evidence — разбор свидетельств и отзыв по этапу

> РП-385 Ф18.15 (режим Диагноста «разбор свидетельств»), Ф18.16 (единый отзыв), Ф18.17 вариант (а) — решения пилота 15.11.2026.
> Правило отзыва — README практикумов «Личное развитие», раздел «Измерение ступени и отзыв по этапу» (`MimEcoSys/Programs`); обещание — `DP.SC.070` «Разбор своего перехода после каждого этапа».

**Что делает.** Разбирает блок «про себя» Чек-листа защиты этапа S0–S3: по каждому признаку следующей ступени говорит «есть», «нет» или «неизвестно» и чем это подтверждено, что изменилось с начала этапа и одно следующее действие. По просьбе собирает единый отзыв вместе с блоком «дела и проекты».

**Чего не делает.** Не присваивает и не меняет ступень (ступень считает диагностика), не записывает результат защиты (РП-522), не сохраняет ничего в профиль. Отзыв — не вторая ступень.

**Двойник не нужен.** Разбор строится только из того, что участник принёс сам: заполненный блок «про себя», Входящее эссе этапа, выписки из своей ИИ-среды. Данные платформы до согласия участника не читаются. Если согласие и двойник есть — добавить в конце строку сверки «написал — видно по данным» по ритму и активности.

## Вход

1. **Этап** — S0, S1, S2 или S3 (спросить, если не назван).
2. **Бланк этапа** — `personal-development/practicums/` в `MimEcoSys/Programs` (локально `~/IWE/Programs/`, перед чтением `scripts/iwe-safe-pull.sh ~/IWE/Programs`): S0 → `S0/defense-checklist.md`, S1 → `S1/S1-2025/defense-checklist.md`, S2 → `S2/S2-2026.3-T/defense-checklist.md`, S3 → `S3/defense-checklist.md` (таблица этапов — раздел README «Чек-лист защиты — общий каркас S0–S3»). Признаки — строки «Я1…Я7» блока «Про себя». Без локальной копии (браузер, участник без своей папки IWE) — бланк по ссылке на GitHub (`https://github.com/MimEcoSys/Programs/blob/main/personal-development/practicums/...`) или текст бланка, который участник прислал вместе с заполненным блоком. Бланк недоступен ни одним способом → сказать об этом и не разбирать по памяти.
3. **Заполненный блок «про себя»** участника — текстом в чате или файлом.
4. **Входящее эссе этого этапа** — для «что изменилось»; нет эссе → строка «с чем сравнивать — неизвестно (нет Входящего эссе)».
5. **Ступень** — собственная самооценка участника через `learning_ctx_get_my_cp_assessment` (только чтение своей записи; это не данные платформы о поведении, согласие на отслеживание для неё не нужно). Статус всегда «самооценка»; нет записи или ошибка → «пока неизвестна». Если участник сам называет ступень, подтверждённую наставником, — указать её с пометкой «со слов участника».
6. **Целевая ступень блока** — из заголовка блока «Про себя» бланка: S0 → 2, S1 → 3, S2 → 4, S3 → 5. Не N+1: этап S1 принимает ступени 1–2, и для ступени 1 «N+1» назвал бы не ту ступень.

## Как ставить вердикт по признаку

| Вердикт | Когда |
|---|---|
| **есть** | Каждое условие признака подтверждено датированным свидетельством. Признак часто содержит несколько условий через запятую или «и» (Я1: частота, длина срыва, перестройка ритма) — нужны все |
| **нет** | Хотя бы по одному условию участник сам описывает поведение ниже порога (порог «около 6 дней в неделю», а пишет «3 дня»; признак «весь набор методов», а пишет, что применяет один) или эпизод противоречит признаку |
| **неизвестно** | По какому-то условию свидетельства нет, оно без даты или слишком общее («стал собраннее»), а «нет» не сработало. Частичное подтверждение — тоже «неизвестно»: назвать, какое условие подтверждено, а какое нет |

- **Датированное свидетельство** — эпизод с датой или неделей этапа и с предметом («13.10 применил недельное планирование»), или период с датой начала и конкретной частотой («с 10.10 шесть дней в неделю»). Дата без года — текущий год.
- «Чем подтверждено» — короткая цитата или пересказ эпизода участника с датой. Своих оценок вместо свидетельства не подставлять.
- Слова признака не переформулировать; сравнивать с порогом из бланка, в скобках у признака дан уровень текущей ступени — он помогает отличить «нет» от «есть».
- **Ответ не про этот признак** («иногда пропускаю» в строке о проекте): для этого признака — «неизвестно, ответ о другом»; если ответ подходит к другому признаку, учесть его там с пометкой «(из строки ЯN)». Вердикт ставится по всему, что относится к признаку, откуда бы оно ни пришло.
- **Нельзя проверить без списка** (например, «весь набор методов», а набор этапа в бланке не перечислен) — «неизвестно», в следующем действии попросить перечислить применённые методы.
- Тексты для человека — простым языком и по реестру понятий и родов (`scripts/concept-kind.py check-text`, если скрипт доступен). Обращение к участнику — на «вы».

## Примеры-образцы уровня

Пока якорных примеров с защит потоков 2026 года нет (РП-385 Ф14.8), разбор идёт с пометкой (решение пилота 15.11.2026, Ф18.17 вариант (а)):

> Образцов с защит ещё нет, а бланк чек-листа пока черновик, поэтому достоверность разбора пониженная: строгость оценки может отличаться от разбора наставника.

Когда образцы появятся в README практикумов, сравнивать свидетельство с образцом своего признака и снимать пометку.

## Выход — разбор «про себя»

```
Ступень N «[название]» (самооценка, [дата]) — или «Ступень пока неизвестна: [чего не хватает]».
Чек-лист S[этап] показывает готовность к ступени M «[название]»: [k] из [m] признаков есть.   (M — целевая ступень блока, вход 6)

Я1 [признак коротко] — есть / нет / неизвестно. [чем подтверждено, дата]
…
Я7 …

Что изменилось с начала этапа: [1–3 строки: было во Входящем эссе → стало в чек-листе]

Одно следующее действие: [одно действие с предметом для самого слабого признака «нет» или «неизвестно»; если всё «есть» — готовность к защите и разговор с наставником о подтверждении ступени]

[пометка о пониженной достоверности, пока нет образцов]
```

- **Названия ступеней:** 1 Случайный, 2 Практикующий, 3 Систематический, 4 Дисциплинированный, 5 Проактивный.
- **Ступени нет** (никакой диагностики) — первая строка «Ступень пока неизвестна»; предложить `/diagnose` (около трёх минут), но разбор всё равно провести. **Диагностика старше 180 дней** — добавить «(устарела, пройдите /diagnose заново)».
- **[m]** — все признаки блока «про себя» бланка (Я1…Я7), включая признаки фокуса этапа.
- **Что изменилось** — только по признакам, о которых есть данные во Входящем эссе; остальные одной строкой «по признакам ЯN… во Входящем эссе данных нет».
- **Одно следующее действие** — для первого по порядку: признак «нет» → признак «неизвестно» без единого свидетельства → признак «неизвестно» с частичным; при равенстве — меньший номер. В едином отзыве так же, только сначала пункты блока «дела и проекты» ниже уровня закрытия (2; у пунктов-событий — 1), затем признаки «про себя».
- Если режим работает в IWE, где ответ человеку заканчивается строкой «Дальше:», она идёт после разбора и называет то же следующее действие.

## Единый отзыв по этапу (Ф18.16)

Когда просят «отзыв по этапу», «полный отзыв», «разбери весь чек-лист»:

1. Блок «дела и проекты» — по скиллу `/project-analysis` (тот же бланк этапа): уровни пунктов, три главных пробела.
2. Блок «про себя» — разбор выше.
3. Свести в один ответ:

```
Ступень N (самооценка, [дата]). Готовность к ступени M: [k] из [m] признаков «про себя» есть; дела и проекты — закрыто [сколько] пунктов из [скольких] (уровень закрытия 2, у пунктов-событий — 1).

Дела и проекты: [три главных пробела из /project-analysis, по строке]
Про себя: [признаки «нет» и «неизвестно», по строке]
Что изменилось с начала этапа: […]
Одно следующее действие: [одно — для самого важного пробела из двух блоков]

[пометка о пониженной достоверности]
```

Одно следующее действие на весь отзыв, не по одному на блок.

## Граничные случаи

| Ситуация | Действие |
|---|---|
| Блок «про себя» не заполнен | Сказать, что разбирать нечего, и предложить заполнить бланк; ступень не обсуждать |
| Участник просит «поставь мне ступень» по чек-листу | Объяснить: ступень считает диагностика (`/diagnose`) или наставник; разбор показывает готовность |
| Свидетельство есть, но о другом признаке | Перенести к нужному признаку и сказать об этом |
| Несколько этапов в одном тексте | Разбирать этап, который назвал участник; другой — отдельным разбором |
